# Kaikata — технический репозиторий (бета)

Рабочие сборки Kaikata и коннекторов для проверки разработчиком. Их видят только телефоны с включённым бета-тестированием.

- Выпуски (Releases) — бета-сборки Kaikata, обновляются в приложении одной кнопкой.
- `catalog.json` и `modules/` — бета-каталог коннекторов.

Для всех пользователей — чистовые репозитории [kaikata-releases](https://github.com/dayu8080/kaikata-releases) и [kaikata-connectors](https://github.com/dayu8080/kaikata-connectors): туда попадает только одобренное.
